01 — Thesis

Pro tool feel. Serious work, serious software.

Functional-dense aesthetic. IBM Plex Sans engineered for product UI. IBM Plex Mono for every number. Warm graphite neutrals because cold slate signals AI dashboard. Signal amber because every dashboard is blue. Cards have hairlines, not shadows. Numbers are tabular. Whitespace is intentional, not generous.

02 — Typography

One sans, one mono.

IBM Plex Sans for everything UI — IBM's product design language, engineered for data-heavy enterprise tools. Stylistic set ss03 for slashed zero in numerics. IBM Plex Mono with tabular figures for every number, every code block, every metadata label. Both designed as a system: identical metrics, mixed-typography never fights.

03 — Color

Warm graphite + signal amber.

Eleven-step neutral, slight yellow undertone — paper, not concrete. Amber primary because instrument panels are amber. Cyan-ink secondary for selected state only. Semantic colors WCAG AA against neutral 50 and neutral 900.

07 — Guardrails

What this system refuses to do.

  • No gradients on buttons, backgrounds, or charts
  • No glassmorphism / backdrop-blur cards
  • No purple-to-pink anything
  • No emoji in UI chrome (Lucide icons only)
  • No shimmer / pulsing "AI" loading states
  • No drop shadows on data panels
  • No centered layouts in admin
  • No pill buttons in admin (mobile CTAs only)
  • No oversized hero numbers (KPI caps at 32px)
  • No system-ui as primary display font
  • No rainbow categorical ramp on charts
  • No "Built for X" marketing-copy patterns
